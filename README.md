# RedBus — Playwright QA Automation

## Project Overview

A personal QA automation project focused on testing key RedBus web application workflows using Playwright.

The project demonstrates web automation, functional validation, regression testing, test design, and AI-assisted QA practices.

## Testing Scope

* Functional Testing
* UI Testing
* End-to-End Testing
* Regression Testing
* Smoke Testing
* Sanity Testing
* Positive Testing
* Negative Testing
* Exploratory Testing
* Cross-Browser Testing
* Test Automation
* AI-Assisted Testing

## Application Areas

The automation scope includes key RedBus workflows such as:

* Homepage navigation
* Bus search
* Source and destination selection
* Travel date selection
* Search results
* Bus filtering and sorting
* Bus selection
* Seat selection
* Passenger information
* Booking workflow
* Navigation and validation

## Automation Framework

**Playwright**

The project is designed around Playwright's capabilities for:

* Browser automation
* Locator-based interaction
* Assertions
* End-to-end testing
* Cross-browser testing
* Automated screenshots
* Test execution and reporting

## Planned Automation Coverage

The automation suite can cover:

1. Open RedBus
2. Enter source and destination
3. Select travel date
4. Search for available buses
5. Validate search results
6. Apply filters
7. Select a bus
8. Validate seat availability
9. Select a seat
10. Validate passenger information workflow

## AI-Assisted Testing

AI-assisted techniques may be used to support:

* Test scenario generation
* Test case refinement
* Locator suggestions
* Test script assistance
* Test coverage analysis
* Test data generation
* Failure analysis
* Test documentation
* Test maintenance

AI-generated suggestions are reviewed and validated by the tester before being used in the final QA workflow.
